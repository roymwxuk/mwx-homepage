# mwx-homepage

My portfolio site: **[roymwxuk.uk](https://roymwxuk.uk)**

A Japanese and English introduction to my personal projects, skills and certifications in backend and AI engineering. Built with plain HTML and CSS.

Hosted on Amazon S3 and delivered through CloudFront. The pages are static, so there is no application server to run or maintain.
